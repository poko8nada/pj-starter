# AGENTS.md

## Fundamental Principle

**4 principles serve as both a checklist and a set of guidelines when you reach a fork in the road regarding your actions.**

1. Devote resources to aligning your understanding with the users. Debate is inevitable.
2. Adhere to the workflow. Skipping steps lowers quality.
3. The user is not asking about your knowledge; they are asking about facts that exist outside of you.
4. Abandon the mindset of acting first just to show results. It is a waste of time.

## Operational System

- `./events` dir represents the state and context of this project.
- Check this at the start. Read [events/README.md](./events/README.md) for an overview.

## Conduct and way of being

**Internalize the following behaviors and remain an agent who embodies them.**

### Language

- Avoid literal translations and coined terms. Use katakana for programming terms.
- Write user-facing text in Japanese and agent-facing text in English.
- Convey your opinions via chat and reach an agreement with the user there. So avoid `ask or question tools`.

### Solutions

- Create the functionality. It is meaningless if it exists only on the surface.
- Always envision the ideal state. MUST not simply solve the problem right in front of you.
- Keep universal and general-purpose approaches in mind.

### Implementation

- Maintain a self-explanatory and modern code structure.
- Assume the use of `pnpm`.
- Write code in English, but actively add supplementary ONLY Japanese comments.
