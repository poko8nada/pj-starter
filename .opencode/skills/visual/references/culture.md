# Culture

Visual reference sites for aligning agent and user on aesthetic direction. Show, don't ask.

## Alignment Workflow

1. Show, don't ask. Instead of "What style do you want?", show two directions and ask "Which is closer?".
2. Use comparison tools to toggle between aesthetics.
3. Once direction is clear, set `motion` and `density` dials.

## Japanese Aesthetic

### Characteristics

- Information density = trust (empty = untrustworthy)
- Low saturation, traditional colors
- Four-script mixing (kanji / hiragana / katakana / latin)
- Multiple entry points in navigation
- Single-page forms with all fields

### Galleries

- [MUUUUU.ORG](https://muuuuu.org/) — 6,196 sites. 35 industry categories, 12 color tags, wa-fu filter. De facto standard in Japan.
- [SANKOU!](https://sankoudesign.com/) — Font taxonomy (mincho / gothic / maru-gothic), traditional & retro filter.
- [Web Design Clip (JP)](https://webdesignclip.com/) — Japan / World subdomains, wa-fu tag, 6,353 sites.
- [IKESAI](https://ikesai.com/) — Premium curated, visual/interaction quality focus.
- [Choooodoii](https://choooodoii.com/) — Verbalizes "why it's good". Tone/style gauges.
- [Japan Web Design Gallery](https://japanwebdesign.com/) — English commentary. For non-Japanese speakers.
- [LP ARCHIVE](https://rdlp.jp/lp-archive/) — 45,735 Japanese landing pages. High-density conversion design.

## American / Western Aesthetic

### Characteristics

- Whitespace = sophistication (empty = trust)
- High saturation, bold typography
- 1-2 font families
- Single-funnel CTA
- Step-by-step forms

### Galleries

- [Awwwards](https://www.awwwards.com/) — Global award. Country filter: [/Japan](https://www.awwwards.com/websites/Japan/) vs [/United States](https://www.awwwards.com/websites/United%20States/).
- [SiteInspire](https://www.siteinspire.com/) — Western minimal as default. [Japanese category](https://www.siteinspire.com/websites/category/japanese) toggle.
- [Godly](https://godly.website/) — Ultra-curated. American high-end agency aesthetic.
- [CSS Design Awards](https://www.cssdesignawards.com/) — SMB-inclusive Western award.
